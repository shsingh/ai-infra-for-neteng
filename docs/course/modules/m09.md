# Module 9 — Observability and the Finale

Reads against: [case study](../case-study.md) work order m09 · build outputs:
[m9 apps](https://github.com/shsingh/ai-infra-for-neteng/blob/master/PLAN.md#83-per-module-apps-course-order) · guide: `docs/labs/lab08-observability.md` (produced in build stage 9).

## Content

1. **Where is the state? (management plane):** CR status fields (True/False + message).
   Attendees build their own show commands from `kubectl get -o jsonpath`.
2. **TMM telemetry/logging (data plane):** centralized logging, diagnostics, and
   support-capture workflows; for the picker path, the Module 8 tmctl tables are the new
   show-tech. In the room demo, a real forwarding-pod log grep for a dropped flow is mapped
   to the firewall rule from Module 7 on the demonstration instance — the log line is the data plane telling the
   management plane what happened.
3. **The 3 a.m. drill (break-fix finale):** each team applies one of the major faults
   themselves (`m4-bgp-secret`, `m4-vxlan-vni`, `m8-epp-selector`, `m7-l4port` — apply,
   diagnose, restore, purely on their own instance), then another team restores it blind;
   speed and diagnosis quality are scored against the documented paths. The
   first diagnostic question, every time: "which plane is broken?" — because that decides
   the tool: CR status (management), the spine container (control), forward-pod
   logs/flows (data).
4. **Wrap-up mapping review:** attendees fill the concept-mapping table, the analogy grid,
   and the planes table from memory ([planes-and-analogies](../planes-and-analogies.md)) —
   the real exam of the day.
5. **What was not covered:** DPU hands-on, telco protocol CRs, IPS, the MPLS-PE Early
   Access path, and the optional modules' full treatments.

## Planes check (the wrap-up exam)

Students place every break-fix of the day on the planes table: the endpoints fault =
management (labels are metadata), the BGP-secret fault = control (session auth), the VNI
fault = data-plane encapsulation, the EPP-selector fault = the L7 control function. If
they can do this cold, the planes model transferred.
